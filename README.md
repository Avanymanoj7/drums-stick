# 🥁 Drum Kit

A simple and interactive **Drum Kit Web Application** built using **HTML, CSS, and JavaScript**.

You can play different drum sounds by **clicking the buttons** or **pressing the corresponding keys on your keyboard**.

## ✨ Features

* 🥁 Seven different drum sounds
* ⌨️ Keyboard controls
* 🖱️ Mouse/click controls
* ✨ Button press animations
* 🎨 Simple and responsive interface
* 🔊 Audio playback using JavaScript

## 🎮 Controls

| Key | Sound     |
| --- | --------- |
| `W` | Tom 1     |
| `A` | Tom 2     |
| `S` | Tom 3     |
| `D` | Tom 4     |
| `J` | Crash     |
| `K` | Kick Bass |
| `L` | Snare     |

You can also **click the buttons** to play the sounds.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* JavaScript DOM Manipulation
* JavaScript Event Listeners
* HTML5 Audio

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure all `.mp3` files are in the same folder as `index.html`.
3. Open `index.html` in your browser.
4. Click the drum buttons or use your keyboard to play.
